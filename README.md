PORTFOLIO DE GUILLAUME SAINSON

Ouvrir index.html dans un navigateur pour voir le site.

index.html         page d'accueil
projets.html       projets, rangés par état
competences.html   boîtes de compétences + programme du bachelor
parcours.html      formation et stages
loisirs.html       loisirs
contact.html       e-mail, LinkedIn, GitHub

css/style.css      toute la mise en forme (couleurs, polices, boîtes)
js/flocon.js       animation du flocon de la page d'accueil
images/            icônes, un sous-dossier par page
                   (voir images/ICONES-A-AJOUTER.txt)

Le menu et le pied de page sont répétés dans chaque fichier .html :
si tu ajoutes une page, pense à ajouter son lien dans le menu des six fichiers.
